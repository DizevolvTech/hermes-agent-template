# Área: <nome>

Copie esta pasta para `areas/<nome>/`, renomeie e indexe em `areas/MAPA.md`.

- `contexto/` — como a área funciona, regras e glossário.
- `rotinas/` — processos recorrentes (passo a passo verificável).
- `projetos/` — projetos ativos da área.
- `skills/` — skills específicas da área (formato `empresa/skills/_templates`).
