# Automações

Uma pasta por rotina: `automation/<key>/` com `README.md` (o que faz, efeitos, kill switch) e o
código (`run.sh`/`run.py`). A `<key>` é a mesma do `REGISTRO-RECORRENCIAS.json` no cérebro.
Copie `_modelo-rotina/`. Saída vai para `reports/` (sanitizada) ou `outbox/` (se precisar de aprovação).
